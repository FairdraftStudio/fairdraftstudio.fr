Outil gratuit

Vos demandes de contact, du mail au tableau

Collez les e-mails que votre formulaire de contact vous envoie. Chaque demande devient une ligne (nom, e-mail, message…), prête à coller dans Google Sheets ou Excel, ou à télécharger en CSV. Tout se passe dans votre navigateur : rien de ce que vous collez n'est envoyé ni enregistré.

Les e-mails de votre formulaire

Copiez le texte de chaque e-mail de notification, sans son en-tête (expéditeur, date). L'outil reconnaît les lignes « Nom : Claire », les blocs « --- Nom --- » et les noms de champ courants (Nom, E-mail, Message…) seuls sur leur ligne, avec la valeur en dessous. Ces e-mails contiennent les coordonnées de vos clients : elles restent sur votre ordinateur.

Une ligne par demande

Collez dans la cellule A1 d'une feuille vide. Dans la copie, les retours à la ligne d'un message deviennent « / » ; le fichier CSV les garde.

Comment l'outil lit vos e-mails

  • Les champs. Une ligne « Nom du champ : valeur », un bloc « --- Nom du champ --- » suivi de la valeur, ou un nom de champ connu seul sur sa ligne, avec la valeur en dessous. Un message sur plusieurs lignes reste entier.
  • Les colonnes. Les noms courants sont regroupés : « Email », « Courriel » et « Adresse e-mail » donnent la même colonne « E-mail ». Les autres champs gardent leur nom. Un champ inconnu placé après le message est ajouté au message.
  • Les demandes. Une nouvelle demande commence quand un champ déjà lu revient (un deuxième « Nom », par exemple).
  • Ce qui est laissé de côté. Les lignes hors des champs, la signature du formulaire (la ligne « -- » et le texte qui suit) et les lignes techniques (adresse IP, navigateur). Le résumé au-dessus du tableau indique combien de lignes hors des champs ont été laissées de côté.
  • Une précaution. Une valeur qui commence par = + - ou @ (un numéro en +33, par exemple) est précédée d'une apostrophe dans la copie et le CSV, pour que le tableur ne la lise pas comme une formule.

Ce que l'outil ne couvre pas

  • Les fichiers d'e-mail. Il lit le texte collé, pas les fichiers .eml ou .msg, et ne se connecte pas à votre messagerie.
  • Les doublons. Une demande collée deux fois donne deux lignes.
  • Les formulaires qui n'envoient pas les réponses. Certaines notifications disent seulement qu'une réponse est arrivée, sans son contenu : les réponses sont alors dans le formulaire lui-même.
  • Tous les formats. Il reconnaît le format par défaut des e-mails de Contact Form 7, WPForms, Elementor et Shopify (relevé dans leur code source ou dans des e-mails publiés), et les lignes « Nom : … ». Avec un autre format, vérifiez le tableau avant de l'utiliser.

Rien de ce que vous collez n'est envoyé ni enregistré : tout se passe dans votre navigateur.
